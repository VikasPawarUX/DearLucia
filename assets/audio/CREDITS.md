# Dear Lucia audio credits

## Soundtrack

One track loops through the whole game.

| Local file | Track and creator | Source and license |
| --- | --- | --- |
| `music/etirwer.m4a` | Etirwer, Kistol | [Creator’s OpenGameArt release](https://opengameart.org/node/20642), CC0 1.0 |

The source release lists [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/), which permits commercial use and redistribution. The local copy was loudness-normalized and encoded to HE-AAC (48 kbps) for browser playback.
